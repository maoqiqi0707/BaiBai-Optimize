# 柏宝绘优化

柏宝绘（ST-BaiBai-Image）的诊断辅助插件。告诉你为什么出图会报「没有返回可解析的 JSON 对象」，并给出参数建议。

## 它不连任何 API

这个插件**不发送任何请求，不读取任何密钥，不需要联网。**

它做的事是站在旁边看：柏宝绘发请求时记下参数，柏宝绘收回复时复制一份试算能不能解析成 JSON。用的都是柏宝绘已经发出去的流量，零成本、零风险。

## 三个功能

### 1. 请求诊断

记录每次出图的请求与返回，失败时判断原因：

| 现象 | 它的判断 | 建议 |
|---|---|---|
| 大括号不配对 / 思考块没闭合 | 被截断 | 调小 max_tokens、降低思考强度 |
| 响应里没有 JSON | 没按格式答 | 降温度、换模型 |
| 有 JSON 但解析失败 | 格式被改写 | 降温度、换直连 |
| 401 / 429 / 5xx | 请求失败 | 看状态码处理 |

平时不用管，失败时打开面板看最新那条。

### 2. 渠道建议

读取柏宝绘当前的渠道配置，算出推荐值，逐项告诉你「现在是什么、建议改成什么、为什么」。

覆盖五项：最大 token、温度、思考强度、超时、流式传输。

**它会自动识别思考型模型**（DeepSeek、QwQ、o1、R1 之类）。如果检测到，会提醒你思考会吃光输出预算，建议把思考强度调低。

### 3. 一键替换

点「一键替换」后会弹出确认，列出要改的每一项，确认后才真正执行，执行完再告诉你改了几项。

**安全边界，这几条是硬性的：**

- 只改五个数值参数，白名单控制。
- **绝不碰 API 地址、密钥、模型名、渠道名。**
- **绝不切换当前渠道。**
- 目标渠道不是当前激活的那个，直接拒绝。
- 改完不自动保存，你还要回柏宝绘点一次「完成」。
- 全程有二次确认，不会静默修改。

API 配错可能导致限流甚至封号，所以这里刻意做得笨一点：每一步都要你确认。

## 悬浮球

设置页有个「显示悬浮球」的勾选框，默认开启。

开着的话，屏幕右侧会有一个圆形按钮，点一下打开诊断面板。可以拖动到任意位置，位置会记住。有新的失败记录时，球上会亮一个红点。

不想看到它就取消勾选，球立刻消失。

## 安装

把 `BaiBai Optimize` 整个文件夹放进：

```
SillyTavern\data\<你的用户名>\extensions\
```

刷新页面（F5）。

**加载顺序**：本插件 `loading_order` 是 90，柏宝绘是 100，所以本插件先加载、先接管 fetch，才能抓到柏宝绘的请求。装好即可，不用管。

## 使用

三个入口：

- 顶部扩展菜单里的「柏宝绘优化」
- 扩展设置页里的「柏宝绘优化」区块
- 悬浮球（如果开着）

面板有两个页签：

- **请求记录**：左边列表，右边详情。红色是失败。
- **渠道建议**：列出五项参数的建议值，最下面有「一键替换」。

## 针对你当前配置的建议

如果你用的是 DeepSeek 系模型，注意「思考强度」：

- `auto` 或 `max` 会让模型输出很长的思考过程
- 柏宝绘的提示词要求在 thinking 里逐字段填表，还要三层自查
- 出 3 张图就是三倍思考量
- 结果就是思考吃光预算，JSON 写不完

所以推荐：**思考强度调低、出图数量降到 1 到 2 张先试试。**

## 文件结构

```
BaiBai Optimize/
├── manifest.json     酒馆识别插件的清单
├── index.js          打包好的成品，装进酒馆的就是它
├── build.mjs         打包脚本
└── src/
    ├── monitor.js    请求监听与诊断
    ├── channels.js   渠道参数读取与建议
    ├── apply.js      参数替换（有白名单）
    ├── floatball.js  悬浮球
    ├── panel.js      面板界面
    └── index.js      入口
```

改完 `src/` 里的文件，在根目录跑 `node build.mjs`。

注意：打包时所有模块拼进同一个作用域，模块级常量都加了唯一前缀，避免重名。

## 已知限制

- 只能观察走 `window.fetch` 的请求。
- 只保留最近 60 条记录，刷新即清空，不落盘。
- 诊断只能事后分析，**不能替柏宝绘重试**，重试逻辑在它内部。
- 一键替换只改数值参数，改不了模型和渠道选择，那些必须你自己在柏宝绘里选。
